# DUST
Domain Under Positive Selection in Tumors

DUST is a R package that aggregates tumor somatic mutations by protein domains, and estimates selection coefficients on missense and protein-truncating mutations in each domain. It takes an input file in the Mutation Annotation Format (MAF), such as those available from the GDC Data Portal or those generated by Variant Effect Predictor (VEP). It produces several intermediate and final output files, which contain mutations mapped to NCBI CDD domains, estimated selection coefficients, and mutation distribution plots. All these files share the same prefix specified by the user. For more details, please refer to the R manual of dust() and other functions. 
## Installation

You can install the development version of DUST like so:

``` 
devtools::install_github('liliulab/dust')
```

## Example

This is a basic example using the TCGA.CHOL data, which is included in the "example/" subfolder.

```{, eval=F}
library(DUST)

wk.dir = 'example'  
output.prefix = 'dust.TCGA.CHOL'
input.file.name = paste0(wk.dir, '/TCGA.CHOL.somatic.maf.gz'); input.compressed = T;
output.folder = wk.dir
N.sim = 1000;
fp.cutoff.rate = 0.1;
rare.mut.cutoff=3;
cnt.cutoff.rate = NULL;
cnt.mis.cutoff = cnt.non.cutoff = cnt.both.cutoff = 6;
steps = 1:7
dust(
  input.file.name,
  output.folder,
  output.prefix,
  N.sim=N.sim,
  fp.cutoff.rate=fp.cutoff.rate,
  rare.mut.cutoff=rare.mut.cutoff,
  cnt.cutoff.rate=cnt.cutoff.rate,
  cnt.mis.cutoff=cnt.mis.cutoff,
  cnt.non.cutoff=cnt.non.cutoff,
  cnt.both.cutoff=cnt.both.cutoff,
  steps=steps)
```
